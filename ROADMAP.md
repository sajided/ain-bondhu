# Ain Bandhu - Future Roadmap

## Phase 1: Enhanced Safety & Accessibility (Next Steps)
- [ ] **Offline Mode (PWA)**: Implement Service Workers so the app works even with intermittent internet.
- [ ] **Voice Support**: Add text-to-speech for bot responses to help users with low literacy.
- [ ] **Geolocation**: Auto-detect user location to suggest the *nearest* police station or OCC.
- [ ] **Quick Hide Gesture**: Implement a "shake to hide" feature that instantly blanks the screen.

## Phase 2: Deeper Legal Integration
- [ ] **Document Generation**: Auto-generate a draft FIR text based on the conversation history that the user can copy.
- [ ] **Lawyer Connect**: A feature to request a callback from a BNWLA volunteer lawyer (requires backend integration).
- [ ] **Case Tracking**: Simple local storage mechanism to track key dates (e.g., "Hearing in 3 days").

## Phase 3: Community & Education
- [ ] **Stories**: Anonymous stories of women who successfully used the law (to build courage).
- [ ] **Video Explainers**: Short 30s videos explaining complex concepts like "Iddat" or "Kabin".
- [ ] **Quiz Mode**: "Do I have a case?" interactive quiz.

## Technical Improvements
- [ ] **Analytics (Privacy Preserved)**: Integrate Plausible/PostHog to track which laws are most queried.
- [ ] **Testing**: Add end-to-end Cypress tests for the critical "safety exit" flow.
- [ ] **Performance**: Optimize bundle size for 2G/3G networks.
